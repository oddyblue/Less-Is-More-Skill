# Using Less Is More With Cursor

This repo includes a Cursor project rule so the `Less Is More` workflow can apply automatically in Cursor.

## In This Repository

1. Open this folder in Cursor.
2. The rule [`.cursor/rules/less-is-more.mdc`](./.cursor/rules/less-is-more.mdc) is committed in the repo.
3. In Cursor, confirm it appears in the project rules UI.

## Use In Another Project

Copy [`.cursor/rules/less-is-more.mdc`](./.cursor/rules/less-is-more.mdc) into that project's `.cursor/rules/` directory.

If you prefer a root instruction file instead, copy or merge [`CLAUDE.md`](./CLAUDE.md).

## Keep In Sync

If you change the core workflow, keep these files aligned:

- [`CLAUDE.md`](./CLAUDE.md)
- [`.cursor/rules/less-is-more.mdc`](./.cursor/rules/less-is-more.mdc)
- [`skills/less-is-more/SKILL.md`](./skills/less-is-more/SKILL.md)
